# Bamdad Alert 1.0.1

This release combines the previously planned 1.0.0 account features with the Bamdad feature set. There is no separate 1.0.0 release.

- Rename display branding to Bamdad Alert; bilingual About page for Bamdad Information Technology Group, Mahdi Nosrati and email contact.
- English default; Persian RTL with bundled Vazir; persistent light/dark/system theme.
- Admin/admin initial account, mandatory password change, scrypt passwords, HttpOnly sessions, login throttling and immediate revocation.
- Administrator/user model; assigned-item visibility and separate create, edit and notification-test permissions.
- Manual software license and API expiry records. Perpetual licenses supported. API secrets are not stored or validated.
- Reusable central alert connections, independent message languages, global/custom/disabled item policies, reminder thresholds and repeat intervals.
- Test notifications with throttling and honest logged-only email status; delivery history with redacted errors.
- Server-side port helper with configuration backup and rollback; UI only generates the command.
- Automatic migration preserves previous per-domain receivers and language settings.
- Updated Ubuntu 24.04 instructions and actual light/dark UI screenshots with synthetic data.

## Upgrade notes

Back up the database and `.env` first. Keep the existing `sslert-data` volume. Check out `v1.0.1` and rebuild with Docker Compose. Initial login is admin/admin and requires a new password. Old ownerless API tokens are rejected; create a user-bound token after changing that user's password. `.env` default email is imported only once; manage receivers in the panel thereafter. Existing items retain their own receivers instead of silently adopting new global settings.

SMS and provider-specific token validation are deferred. Mail/Telegram tests use the supplied connection credentials; this source release does not configure a provider account for you. Instructions, source and screenshots are included; Docker Compose builds the images locally.
