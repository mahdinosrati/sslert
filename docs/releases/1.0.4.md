# Bamdad Alert 1.0.4

- داشبورد عملیاتی با کارت‌های خلاصه، موارد نیازمند اقدام، نمودار بازه‌های مستقل و تفکیک میزبان از اعتبار
- جدول قابل مرتب‌سازی و صفحه‌بندی، دسترسی مستقیم به رکوردهای دستی و سیاست هشدار، و خلاصه آخرین ارسال‌ها
- ثبت ۱ تا ۵۰ گیرنده برای SMTP و Resend، حذف تکرار و اعتبارسنجی نشانی‌ها
- دکمه ارسال ایمیل آزمایشی به تمام گیرنده‌های ذخیره‌شده و نمایش ارسال ناقص SMTP
- مستندات و تصاویر فارسی روشن/تاریک به‌روز شدند

Upgrade: back up the database, `.env` and `notification.key` if present, check out `v1.0.4`, then run `docker compose up -d --build`. Existing users, records, policies and single-recipient email settings are preserved.
