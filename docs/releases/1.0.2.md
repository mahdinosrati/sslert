# Bamdad Alert 1.0.2 — هشدار بامداد

- ثبت دستی دامنه داخلی و گواهی SSL سازمانی با نام میزبان، صادرکننده/ثبت‌کننده، تاریخ انقضا و مشخصات گواهی.
- استفاده از هشدارهای عمومی یا اختصاصی برای موارد دستی؛ بدون اتصال شبکه یا ذخیره کلید خصوصی.
- حفظ رکوردها، واگذاری کاربران و سیاست‌های هشدار در مهاجرت از 1.0.1.
- تیک نمایش رمز عبور و وسط‌چین‌شدن لوگو و متن صفحه ورود.
- لوگوی تب مرورگر و نام فارسی «هشدار بامداد».
- آیکون ایمیل و تلگرام توسعه‌دهنده در درباره ما.

Back up the database and environment before rebuilding. Migration 0008 runs automatically and preserves previous manual records and user assignments. The password-visibility checkbox is off by default. Automatic public-domain monitoring remains available.
