# Bamdad Alert 1.0.8

## فارسی

- پشتیبانی از پورت ۸۰ در تنظیمات و دستور سرور؛ نشانی استقرار داخلی `http://panel.bkls.org` بدون پورت و گواهی.
- هشدار یک‌باره در روزهای ۳۰، ۲۰، ۱۰، ۷ تا ۱ و روز انقضا. پس از وقفه فقط آخرین مرحله جبران می‌شود؛ بعد از هشدار نهایی تکرار روزانه نداریم.
- جلوگیری از تکرار به تفکیک رکورد، منبع، کانال، مقصد و تاریخ انقضا؛ تمدید چرخه جدید ایجاد می‌کند. خطا پس از ۱۵ دقیقه در نوبت بعدی پایش دوباره تلاش می‌شود.
- اطلاعات تماس و کانال‌های دریافت کاربران، گیرنده‌های کاربری سراسری یا اختصاصی رکورد و ویرایش اشتراک‌ها از صفحه کاربر. مجوز مشاهده مستقل است؛ مجوزها و ورود ۸ ساعته LDAP حفظ می‌شوند.
- ارسال جداگانه ایمیل و تست ایمیل برای هر مقصد، تاریخچه مستقل و حذف مقصد تکراری؛ آدرس گیرنده در تاریخچه فقط به مدیر نمایش داده می‌شود.
- پیش‌نویس غیرفعال پیامک با آدرس API، شناسه الگو، ترتیب متغیرها، شماره تست و توکن رمز‌شده. ارسال واقعی منتظر اطلاعات الگو، قرارداد پاسخ درگاه و شماره تست است.
- راهنما و تصاویر فارسی روشن/تاریک به‌روز شده‌اند.

## English

Port 80 support, one-shot expiry milestones, latest-only catch-up, durable per-recipient renewal cycles, administrator-managed user contacts/subscriptions, private individual email delivery and disabled SMS pattern drafts. LDAP roles, panel grants and eight-hour sessions remain unchanged.

### Upgrade notes

Back up SQLite, `.env` and `notification.key` before upgrading. Migration `0011_notification_milestones.sql` preserves users, permissions, sessions, records, connections and history. It adds contact/routing fields and durable milestone claims, and moves existing policies to the approved schedule `[30,20,10,7,6,5,4,3,2,1,0]`. Disabled policies remain disabled; connection lists and inheritance remain intact. Legacy repeat mode is still selectable. A first run may send the latest due stage once; old history is not rewritten as new milestone claims.

Dates are compared as UTC calendar dates. History retention does not erase completed milestone claims. Disabled user subscriptions are skipped; fixed destinations on a connection are independent and must be removed separately when appropriate.

SMS sending remains disabled in this release. The gateway adapter must be completed and tested after template details and the test number arrive.
