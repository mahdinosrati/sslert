# Bamdad Alert 1.0.3

- داشبورد جامع تمام اعتبارها با جست‌وجو، فیلتر و کارت‌های وضعیت
- نمایش رمز هنگام ساخت یا بازنشانی حساب و حذف امن کاربر/ادمین
- تنظیمات SMTP سازمانی و Resend در پنل، ذخیره رمزنگاری‌شده رمز و کلید ایمیل
- تاریخچه ارسال با نام مورد و ارتباط، کانال، فیلتر و صفحه‌بندی
- مستندات فارسی و انگلیسی و تصاویر روشن/تاریک به‌روز شدند

Upgrade: back up the database and `.env`, check out `v1.0.3`, then run `docker compose up -d --build`. Existing accounts and monitored items are preserved. SMTP requires your mail-server settings; credentials are not preconfigured. Preserve `notification.key` alongside database backups after configuring email secrets.
